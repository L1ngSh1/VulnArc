# AI-Assisted Research

```text
Human intuition → Independent hypothesis → AI independent analysis → Compare
→ Challenge assumptions → Manual code review → Runtime reproduction
→ Validated / Rejected → Pattern extraction → Improved human intuition
```

The human researcher is the final security judge. AI acts as a code navigator, hypothesis generator, adversarial reviewer, reasoning assistant, and attack-surface expander. AI output is an evidence lead, never a security conclusion. Record model/harness details when relevant without coupling the schema to one provider.
