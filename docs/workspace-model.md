# Workspace Model

The public `VulnArc/` repository contains methodology, tools, templates, sanitized experiments, disclosed cases, and public patterns. A separate external `VulnArc-Research/` path contains undisclosed hypotheses, candidates, reproduction evidence, embargoed records, and private disclosure material. Do not create `private/` or `embargoed/` under the public repository. Pass the external path with `--workspace`; no command uploads or pushes.
