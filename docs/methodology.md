# Methodology

1. Map trust boundaries and attack surfaces. 2. State a falsifiable security invariant and hypothesis. 3. Seek supporting and counter-evidence. 4. Promote only to candidate after code evidence. 5. Manually reproduce in an authorized environment. 6. Mark validated or rejected and preserve the reasoning. 7. Coordinate disclosure before a sanitized public case. 8. Extract reusable patterns.

Validated means supported by reproducible evidence and human judgment; it does not itself mean publicly disclosed.
